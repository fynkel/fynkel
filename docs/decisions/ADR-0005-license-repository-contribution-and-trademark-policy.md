# ADR-0005: License repository contribution and trademark policy

**Status:** Proposed (open)  
**Date:** 2026-09-19  
**Related:** `docs/blueprint.md`

## Context

Licensing must be decided before any public publication, but the repository will be private until M3.

## Decision

Deferred. Default proposal for discussion before the M3 public push: engine/SDK/tooling under `MIT OR Apache-2.0`; separate trademark policy for the Fynkel name/logo; per-asset licenses for samples; DCO for contributions; monorepo; prebuilt binaries via GitHub Releases.

## Consequences

Nothing is published to pub.dev or crates.io until this ADR is accepted. All source files are written so that adding license headers later is mechanical.
