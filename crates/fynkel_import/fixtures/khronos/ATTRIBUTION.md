# Khronos glTF sample assets

Rigged, animated models from the Khronos Group's
[glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
repository, committed as the importer's outside fixtures (blueprint
§19.2d scope rule, 2026-09-21: an item passes only on content its
implementer did not make). Each `<Model>.README.md` is the upstream
metadata file, verbatim; the licences below are quoted from them.

Fetched 2026-09-21 from the `main` branch. These files are the only
binaries in the repository that no committed script regenerates; they
are never modified here. `BrainStem` was considered and left out: its
upstream licence is a Poser EULA, not a Creative Commons one.
