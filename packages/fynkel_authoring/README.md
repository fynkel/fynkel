# package:fynkel_authoring

The editor's Dart surface over the **authoring ABI** — `crates/fynkel_authoring`
reached through `fynkel_native`'s `fynkel_authoring_*` entry points
(`crates/fynkel_native/include/fynkel_authoring.h`, cargo feature
`authoring`). One `AuthoringSession` per editor window, one `DocumentHandle`
per open scene, prefab or material; every edit is one atomic transaction with
byte-exact undo; every read is JSON. Blueprint §19.2e item 1, ADR-0016.

**Games never depend on this package.** The runtime a game builds through
`package:fynkel`'s hook has none of these symbols; this package's pubspec
opts in with

```yaml
hooks:
  user_defines:
    fynkel:
      features: [authoring]
```

which makes the hook build the same library with `--features authoring`
(`cargo build -p fynkel_native --no-default-features` exports no
`fynkel_authoring_*` symbol — CI checks). The bindings are generated by
`ffigen` from the header (`dart run ffigen --config ffigen.yaml`) onto the
same code asset as `package:fynkel` (`package:fynkel/fynkel_native`).

## Use

```dart
import 'package:fynkel_authoring/fynkel_authoring.dart';

final session = AuthoringSession();
final project = session.openProject('/path/to/game');      // read-only when its lock is newer
final scene = session.openDocument('assets/scenes/main.scene.json');   // or by asset id

final applied = scene.apply([
  Command.createObject(name: 'Lamp', components: [
    componentSpec('fynkel.Transform', data: {'position': [0, 2, 0], 'rotation': [0, 0, 0, 1], 'scale': [1, 1, 1]}),
    componentSpec('fynkel.PointLight', data: {'color': [1, 1, 1], 'intensity': 5, 'range': 10}),
  ]),
], baseRevision: scene.state.revision);
if (!applied.ok) print(applied.allDiagnostics);   // FYN-E0001 when the revision was stale: nothing changed

scene.undo();            // byte-exact
scene.redo();
scene.save();            // canonical, in place; the asset database is rescanned
session.dispose();
```

- `AuthoringSession`: `openProject` / `closeProject` / `project`,
  `openDocument(pathOrId)`, `documents`, `query(kind, args)` and the typed
  queries (`commands`, `validateProject`, `assets`, `asset`, `dependents`,
  `schemas`, `schema`, `metadata`), `rescan(paths)`, `events` (a broadcast
  `Stream<AuthoringEvent>`: project opened/closed, document opened/changed/
  closed, assets changed), `dispose`.
- `DocumentHandle`: `state` (revision, dirty, canUndo/canRedo, history,
  readOnly), `apply(commands, baseRevision:)` → `Applied` (committed when
  `ok`, else rolled back with the diagnostics; `isConflict` for a stale
  revision), `undo` / `redo` → `Replayed`, `save({path})`, `reload`, `close`,
  `root()` (the document as JSON), `inspect()`, `validate()`, `changes`.
- `Command`: a builder per §11.1 command (`createObject`, `deleteObject`,
  `renameObject`, `setObjectActive`, `reparentObject`, `duplicateObject`, `addComponent`,
  `removeComponent`, `setField`, `unsetField`, `assignAsset`,
  `instantiatePrefab`, `setPrefabOverride`, `revertPrefabOverride`,
  `setDocumentField`, `unsetDocumentField`, `createMaterial`,
  `saveDocument`).
- `Diagnostic`: the ADR-0014 record (`code`, `severity`, `message`,
  `document`, `pointer`, `id`, `line`, `column`, `suggestion`, `related`).
- `AuthoringException`: a refused or failed call — `status` (the ABI's),
  `diagnostics`, `isConflict`, `isReadOnly`, `isNothingToReplay`,
  `isPoisoned` (dispose the session and open a new one).

Change notification is a plain Dart `Stream` (the package is
Flutter-independent, like `package:fynkel`); the editor app wraps it in
whatever its widgets listen to.

## Test

```sh
dart pub get && dart analyze --fatal-infos && dart test   # Flutter's dart
```

`test/session_test.dart` drives a complete session over the ABI on a
private copy of `crates/fynkel_document/fixtures/project`: every command,
undo back to the original bytes, save, the stale-revision conflict, a
material's `base_color`, `duplicateObject` of the rig.
