# Security

Please don't report a security problem in an issue. Use
[a private report](https://github.com/fynkel/fynkel/security/advisories/new)
instead. Say what it lets someone do and how to make it happen.

Fynkel is a 0.x preview: fixes go into the newest version only.

What matters most here: a model, picture, sound or font that crashes a game
or reaches memory it shouldn't, and anything that could change the engine's
libraries between the release and an app (each package holds their hashes).
