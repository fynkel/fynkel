---
title: The examples
description: Whole games and feature scenes in the repository's examples folder, simplest first.
---

Each is a Flutter app in
[`examples/`](https://github.com/mooumari/fynkel/tree/main/examples) of the
repository, with its own tests. Run one with `flutter run -d macos` in its
folder.

| Example | What it is |
| --- | --- |
| [hello](https://github.com/mooumari/fynkel/tree/main/examples/hello) | One turning cube: the code on the front page |
| [roll](https://github.com/mooumari/fynkel/tree/main/examples/roll) | Roll a ball, take the gems: physics, a camera kept out of walls and a HUD ([the tutorial](/tutorials/roll/)) |
| [starfall](https://github.com/mooumari/fynkel/tree/main/examples/starfall) | A portrait phone game: catch falling stars by touch, pooled objects and sparks, Flutter screens, a saved best score ([the tutorial](/tutorials/starfall/)) |
| [pocket_hole](https://github.com/mooumari/fynkel/tree/main/examples/pocket_hole) | A portrait block-collecting game with touch controls, progression and mobile projects |
| [garden](https://github.com/mooumari/fynkel/tree/main/examples/garden) | A character in a garden, loaded from models; an orbit camera |
| [coins](https://github.com/mooumari/fynkel/tree/main/examples/coins) | Walk about picking up coins, level after level; triggers and a Flutter HUD |
| [arena](https://github.com/mooumari/fynkel/tree/main/examples/arena) | A small top-down game: waves, health, signals, tweens, pause |
| [sheepdog](https://github.com/mooumari/fynkel/tree/main/examples/sheepdog) | A whole game that feels like an app: a title screen, pause menu, settings, rebindable keys, levels and a minimap |
| [bowling](https://github.com/mooumari/fynkel/tree/main/examples/bowling) | Ten-pin bowling on physics: rigidbodies, a mesh collider, gestures |
| [lab](https://github.com/mooumari/fynkel/tree/main/examples/lab) | One scene per feature, with buttons and sliders to try it by hand |
| [scale](https://github.com/mooumari/fynkel/tree/main/examples/scale) | Not a lesson: 10,000 objects, to measure speed |
