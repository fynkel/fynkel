# ADR-0001: 1.0 scope and native-first policy

**Status:** Accepted  
**Date:** 2026-09-19  
**Related:** `docs/blueprint.md`

## Context

Fynkel is being built by one full-time developer with AI tooling. The motivations are a Flutter/Dart 3D-engine gap, an AI-native tooling thesis, and portfolio value. The first users are the author, Flutter developers new to 3D, and AI agents building games.

## Decision

Fynkel 1.0 is a native-first engine: Rust runtime, `wgpu`, `hecs` behind `fynkel_ecs`, Dart gameplay, Flutter UI, optional desktop editor. The §1.2 reference game is the scope oracle. Browser, cloud, multiplayer, terrain, navmesh, shader graph, visual scripting, plugin ABI, consoles, and XR are post-1.0. The repository stays private until M3 (playable reference game).

## Consequences

Every feature proposal must cite the reference game or a pilot project. Work-in-progress stays narrow; milestones are gates, not dates.
