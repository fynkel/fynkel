# fynkel_physics

Physics for [Fynkel](https://pub.dev/packages/fynkel) games, as Unity has it, on
[Rapier](https://rapier.rs): rigidbodies, colliders, triggers, joints, queries
and a character controller. A game without it ships none of it.

```sh
flutter pub add fynkel_physics
```

The guide is at [fynkel.com](https://fynkel.com).
