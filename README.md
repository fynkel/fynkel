# Fynkel

A code-first 3D game framework for Flutter and Dart, with a Rust
renderer (wgpu) and ECS (hecs) underneath.

Fynkel 2 is a fresh start. You write your game in Dart. There are no
scene files, prefabs, JSON or editor. See
[ADR-0001](docs/decisions/0001-fynkel-2-code-first.md) for the decision
and the stage 1 scope.

Fynkel 1, with the editor, the asset pipeline and the full renderer, is
archived as tag `fynkel-1-final` and branch `fynkel-1`.
